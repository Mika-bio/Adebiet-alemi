# Әдебиет Әлемі

Қазақ мектептеріне арналған әдебиет платформасы (Next.js + TypeScript + Tailwind).

## Іске қосу

```bash
npm install
npm run dev
```

## Кіру

Тіркелу формасы арқылы жаңа аккаунт жасауға болады (аты, жөні, логин, құпия сөз, рөл).

Алдын ала бар аккаунттар:

| Рөл | Логин | Құпия сөз | Аты-жөні |
|-----|--------|-----------|----------|
| Оқушы | aigul | okus123 | Айгүл Нұрланова |
| Мұғалім | erlan | mugalim123 | Ерлан Қасымов |
| Оқушы | student | student123 | Айгүл Нұрланова |
| Мұғалім | teacher | teacher123 | Ерлан Қасымов |

Авторизация `localStorage` арқылы жұмыс істейді (`lib/auth.tsx`, `lib/data.ts`).

## Бөлімдер

1. **Auth** — кіру / тіркелу / шығу, оқушы және мұғалім рөлдері
2. **Кітаптар** — ~30 кітап, бет аудару оқырманы
3. **Тапсырмалар** — 60 тапсырма + «Қатемен жұмыс»
4. **Видеолар** — YouTube тарихи / әдеби фильмдер
5. **Музыка** — терме мен күй, кезегімен HTML audio плеер
6. **Ақындар** — өмірбаян карточкалары

## Cloudflare Pages (static export)

`output: 'export'` қосылған. Жинау және deploy:

```bash
npm run build
npx wrangler pages deploy out --project-name=adebiet-alemi
```

`wrangler@3` — Node 20 үйлесімді.
